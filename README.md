## 🛠️ Tech Stack
- ⚛️ Next.js (TypeScript)
- 🎨 Tailwind CSS
- 🧩 shadcn/ui (`components.json`)
- 📦 content-collections (`content-collections.ts`)
- 📦 pnpm

## ⚡ Getting Started

Install deps:
```bash
pnpm install
```

Run dev server:
```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) 🌐

Build for prod:
```bash
pnpm build
pnpm start
```

## 📂 Project Structure
```
public/     static assets
src/        app code, components, pages
```
